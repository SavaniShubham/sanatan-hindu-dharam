# Sanatan Hindu Dharam — Media CDN Assets

This repository hosts the sacred audio library and high-resolution wallpapers used by the Sanatan Hindu Dharam mobile application.

## Directory Structure
- /audio/ — 60 Devotional Bhajans, Aartis, and Chalisas
- /wallpapers/ — 50 HD Sacred Deity Wallpapers

Assets are served worldwide via Fastly & jsDelivr CDN.
